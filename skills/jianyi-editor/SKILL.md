# 剪易 EasyCut 结构化剪辑

1. 找到用户的剪易项目路径，确认存在 `cli/jianyi.mjs`。不要假定当前目录或安装路径。
2. 按需读取项目的 `cli/README.md` 和 `cli/example.json`，以其字段及能力范围为准。
3. 取得用户授权使用的素材及剪辑时间，写入工作目录下的 JSON。所有时间单位为秒；素材路径相对配置文件目录。未知素材时长不要编造，要求明确片段范围，或用已有可用工具读取。第一版没有自动全长和媒体分析能力。
4. 执行 `node <项目路径>/cli/jianyi.mjs validate <配置路径>`，检查 JSON 结果和退出码。没有 Node.js 时说明必要依赖，不擅自安装。
5. 执行 `create <配置路径> --output <新的作品目录>`。不删除旧草稿以绕过目录已存在错误；不更改原始素材。无需 npm install、ffprobe 或后端服务。
6. 返回生成目录、草稿名称、ID、时长及检查限制。告诉用户在网页草稿列表选择输出的父目录并打开草稿，确认预览后调优、保存及导出。
7. 查看网页修改结果时，用 `list <父目录>` 找 ID，再用 `inspect <父目录> --draft <ID>` 只读查看。inspect 是内部快照，不是 create 输入。第一版不支持增量修改已有草稿。

不要把配置验证成功称为视频渲染成功。CLI 未解码媒体，实际时长及编码兼容性由网页恢复检查。只有检查过预览和导出文件才能报告相应成功。
